# C++ Utility Programs

> 📅 **Last updated:** 2026-07-18  

A collection of small C++ programs for everyday calculations – ideal for beginners learning C++ or anyone needing quick command‑line tools.

## 🧮 Programs Included

| Program | File | Description |
| :--- | :--- | :--- |
| **Budget Manager** | `budget-management.cpp` | Calculates total expenses and net savings from monthly income (groceries, entertainment, education). |
| **Pythagoras Theorem** | `pythagoras.cpp` | Computes the hypotenuse of a right‑angled triangle given perpendicular and base. |
| **Quadratic Solver** | `quadratic.cpp` | Solves quadratic equations `ax² + bx + c = 0`, handles real and complex roots. |
| **Square Root** | `sqrt_calculator.cpp` | Computes the square root of any non‑negative number using the built‑in `sqrt()` function. |

## ⚙️ Compilation & Execution

All programs use only the standard C++ library – no external dependencies.

```bash
# Compile any program
g++ filename.cpp -o program_name

# Run the executable
./program_name
